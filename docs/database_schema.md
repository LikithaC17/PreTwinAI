# PreTwinShop AI - Database Schema Documentation

The application uses an SQLite 3 database (`pretwinshop.db`) with parameterized queries, ACID compliance, and foreign key relationships.

## Table Definitions

### 1. `users`
Represents customer demonstration accounts.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Unique user identifier |
| `username` | TEXT | NOT NULL | User display name (e.g. Alex Johnson) |
| `email` | TEXT | UNIQUE, NOT NULL | Account email address |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Account creation timestamp |
| `updated_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Last profile modification |

### 2. `shopping_preferences`
Stores explicit customer affinities and financial bounds.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Unique preferences ID |
| `user_id` | INTEGER | FOREIGN KEY (`users.id`) | Owning user identifier |
| `preferred_categories` | TEXT | JSON | Serialized list of preferred product categories |
| `budget_min` | REAL | DEFAULT 0.0 | Minimum comfortable spending range |
| `budget_max` | REAL | DEFAULT 5000.0 | Hard budget ceiling for recommendations |
| `preferred_brands` | TEXT | JSON | Serialized list of preferred brand names |
| `product_requirements` | TEXT | JSON | Serialized dictionary of specific criteria |
| `shopping_frequency` | TEXT | DEFAULT 'monthly' | 'weekly', 'biweekly', 'monthly', 'quarterly' |
| `shopping_goals` | TEXT | NULLABLE | Primary shopping objective summary |
| `notes` | TEXT | NULLABLE | Freeform persona notes |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Record creation |
| `updated_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Last update |

### 3. `purchase_history`
Stores voluntarily provided past purchases for cadence analysis.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Record identifier |
| `user_id` | INTEGER | FOREIGN KEY (`users.id`) | Owning user ID |
| `product_id` | INTEGER | NULLABLE | Linked product catalogue ID if known |
| `product_name` | TEXT | NOT NULL | Name of purchased product |
| `category` | TEXT | NOT NULL | Category name |
| `brand` | TEXT | NULLABLE | Brand name |
| `price` | REAL | NOT NULL | Price paid at time of purchase |
| `purchase_date` | DATE | NOT NULL | ISO format date (YYYY-MM-DD) |
| `quantity` | INTEGER | DEFAULT 1 | Units purchased |
| `notes` | TEXT | NULLABLE | Contextual user notes |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Log timestamp |

### 4. `products`
Demonstration catalogue containing 50 realistic items across 8 categories.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Unique product SKU |
| `name` | TEXT | NOT NULL | Product title |
| `category` | TEXT | NOT NULL | Category (e.g. Computer Accessories) |
| `brand` | TEXT | NOT NULL | Brand manufacturer |
| `price` | REAL | NOT NULL | Retail price in USD |
| `specifications` | TEXT | JSON | Technical specification key-value pairs |
| `description` | TEXT | NOT NULL | Detailed marketing / functional description |
| `image_url` | TEXT | NULLABLE | Visual image or SVG placeholder path |
| `source_type` | TEXT | DEFAULT 'demo' | Data source provenance |
| `rating` | REAL | DEFAULT 4.5 | User satisfaction rating (1.0 - 5.0) |
| `stock` | INTEGER | DEFAULT 50 | Inventory units available |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Seeding timestamp |

### 5. `shopping_goals`
Explicit milestones or shopping objectives set by the customer.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Goal ID |
| `user_id` | INTEGER | FOREIGN KEY (`users.id`) | Associated user |
| `goal_title` | TEXT | NOT NULL | Goal title |
| `goal_description` | TEXT | NULLABLE | Detailed goal specifications |
| `target_date` | DATE | NULLABLE | Target completion date |
| `budget` | REAL | NULLABLE | Target budget allocated for this goal |
| `status` | TEXT | DEFAULT 'active' | 'active', 'achieved', 'abandoned' |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Creation time |
| `updated_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Last update |

### 6. `predictions`
Anticipated shopping requirements generated by Agent B.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Prediction ID |
| `user_id` | INTEGER | FOREIGN KEY (`users.id`) | Target user |
| `run_id` | TEXT | NOT NULL | Unique execution run UUID |
| `predicted_category`| TEXT | NOT NULL | Category anticipated |
| `predicted_product` | TEXT | NULLABLE | Specific item anticipated |
| `reason` | TEXT | NOT NULL | Heuristic rule justification |
| `supporting_evidence`| TEXT | JSON | Observational data points |
| `estimated_timeframe`| TEXT | NULLABLE | Replenishment window estimate |
| `confidence_score` | REAL | NOT NULL | Heuristic confidence (0.0 - 1.0) |
| `confidence_label` | TEXT | NOT NULL | 'High', 'Medium', 'Low' |
| `recommended_action`| TEXT | NULLABLE | Next action for the user |
| `status` | TEXT | DEFAULT 'active' | 'active', 'dismissed', 'fulfilled' |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Timestamp |

### 7. `recommendations`
Ranked product suggestions proposed by Agent E.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Recommendation ID |
| `user_id` | INTEGER | FOREIGN KEY (`users.id`) | Target user |
| `run_id` | TEXT | NOT NULL | Execution run UUID |
| `product_id` | INTEGER | FOREIGN KEY (`products.id`) | Recommended product |
| `product_name` | TEXT | NOT NULL | Product title |
| `category` | TEXT | NOT NULL | Category |
| `price` | REAL | NOT NULL | Product price |
| `rank` | INTEGER | NOT NULL | Recommendation position (1, 2, 3...) |
| `score` | REAL | NOT NULL | Computed relevance score |
| `reason` | TEXT | NOT NULL | Synthesized justification from Agent F |
| `budget_fit` | TEXT | NOT NULL | 'Excellent', 'Good', 'Tight', 'Over Budget' |
| `alternatives` | TEXT | JSON | Cheaper or comparable alternatives |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Timestamp |

### 8. `product_comparisons`
Side-by-side spec comparison runs produced by Agent D.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Comparison ID |
| `user_id` | INTEGER | FOREIGN KEY (`users.id`) | Requesting user |
| `run_id` | TEXT | NOT NULL | Run UUID |
| `product_ids` | TEXT | JSON | Array of compared product IDs |
| `comparison_data` | TEXT | JSON | Serialized specification comparison matrix |
| `winner_id` | INTEGER | NULLABLE | Winning candidate product ID |
| `winner_reason` | TEXT | NULLABLE | Justification for selected winner |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Timestamp |

### 9. `agent_runs`
Audit telemetry logging genuine agent function executions.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Run log ID |
| `user_id` | INTEGER | NOT NULL | Target user ID |
| `run_id` | TEXT | NOT NULL | Shared pipeline run UUID |
| `agent_name` | TEXT | NOT NULL | Agent Class Name (e.g. ProductDiscoveryAgent) |
| `task` | TEXT | NOT NULL | Subtask description |
| `status` | TEXT | NOT NULL | 'success', 'error', 'partial' |
| `input_summary` | TEXT | NULLABLE | Serialized input arguments summary |
| `output_summary` | TEXT | NULLABLE | Execution outcome summary |
| `execution_time_ms`| INTEGER| NOT NULL | Measured function runtime in milliseconds |
| `error_message` | TEXT | NULLABLE | Traceback / error message if failed |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | ISO Timestamp |

### 10. `user_feedback`
User ratings and comments on recommendations.
| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Feedback ID |
| `user_id` | INTEGER | NOT NULL | Submitting user ID |
| `item_type` | TEXT | NOT NULL | 'prediction', 'recommendation', 'product' |
| `item_id` | INTEGER | NOT NULL | ID of target entity |
| `feedback_type` | TEXT | NOT NULL | 'like', 'dislike', 'rating', 'helpful' |
| `rating` | INTEGER | NULLABLE | Star rating (1-5) |
| `comment` | TEXT | NULLABLE | Optional user remarks |
| `created_at` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | Feedback timestamp |
