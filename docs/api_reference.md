# PreTwinShop AI - API Reference Documentation

All endpoints return JSON responses. Errors follow the schema: `{"error": "message", "code": 400}`.

---

### Products API

#### `GET /api/products`
Retrieve catalogue products with optional filtering.
- **Query Parameters:**
  - `category` (string, optional): Filter by category.
  - `min_price` (float, optional): Lower bound.
  - `max_price` (float, optional): Upper bound.
  - `search` (string, optional): Keyword search across product name and description.
  - `limit` (integer, optional, default: 50): Number of results to return.
- **Response:**
  ```json
  {
    "products": [
      {
        "id": 1,
        "name": "Logitech MX Master 3S Wireless Mouse",
        "category": "Computer Accessories",
        "brand": "Logitech",
        "price": 99.99,
        "rating": 4.8,
        "stock": 45,
        "specifications": { "sensor": "8000 DPI Darkfield", "connectivity": "Bluetooth + Logi Bolt" }
      }
    ],
    "total": 50,
    "categories": ["Computer Accessories", "Electronics", "..."]
  }
  ```

#### `GET /api/products/<int:id>`
Fetch a single product by primary key ID. Returns 404 if not found.

### Profile & Twin API

#### `GET /api/profile`
Retrieves the active demonstration shopping twin profile, user preferences, and goals.
- **Response:**
  ```json
  {
    "user": { "id": 1, "username": "Alex Johnson", "email": "alex@demo.pretwinshop.ai" },
    "preferences": {
      "preferred_categories": ["Electronics", "Computer Accessories"],
      "preferred_brands": ["Sony", "Logitech"],
      "budget_min": 500.0,
      "budget_max": 5000.0,
      "shopping_frequency": "monthly"
    },
    "goals": [
      { "id": 1, "goal_title": "Complete Home Office Setup", "budget": 1500.0 }
    ]
  }
  ```

#### `PUT /api/profile`
Update twin preferences and financial constraints.
- **Payload:**
  ```json
  {
    "preferred_categories": ["Electronics", "Computer Accessories"],
    "preferred_brands": ["Sony", "Logitech", "Philips"],
    "budget_min": 500.0,
    "budget_max": 5000.0,
    "shopping_frequency": "monthly"
  }
  ```

#### `DELETE /api/profile`
Reset the demonstration profile back to original initial defaults.

### Purchase History API

#### `GET /api/purchase-history`
Returns all voluntary purchase records for the active profile.

#### `POST /api/purchase-history`
Records a past purchase.
- **Payload:**
  ```json
  {
    "product_name": "Logitech C920s HD Pro Webcam",
    "category": "Computer Accessories",
    "brand": "Logitech",
    "price": 79.99,
    "quantity": 1,
    "notes": "For remote team video calls",
    "purchase_date": "2026-09-15"
  }
  ```

#### `DELETE /api/purchase-history/<int:id>`
Removes a specific purchase record.

### Predictive & Recommendation API

#### `GET /api/predictions`
Returns active predictions generated by Agent B.

#### `POST /api/predictions`
Directly triggers Agent B to generate fresh predictions based on purchase intervals.

#### `GET /api/recommendations`
Returns active ranked recommendations.

#### `POST /api/recommendations`
Executes the full end-to-end 6-agent pipeline via `AgentOrchestrator`.
- **Response:**
  ```json
  {
    "run_id": "c1f728c3-4f24-4f01-b203-888e7d25e012",
    "status": "success",
    "total_cost": 369.93,
    "budget_status": "Excellent",
    "recommendations": [ ... ],
    "agents_executed": [
      { "agent": "Agent A: Shopping Twin", "duration_ms": 12, "status": "success" },
      { "agent": "Agent B: Predictive Shopping", "duration_ms": 15, "status": "success" }
    ],
    "workflow_summary": "Successfully executed 6 agents in 120ms."
  }
  ```

#### `POST /api/comparisons`
Executes Agent D to compare specific candidate products.
- **Payload:**
  ```json
  {
    "product_ids": [1, 2, 3]
  }
  ```

### Telemetry & Feedback API

#### `GET /api/agent-runs`
Fetches recorded function telemetry from the `agent_runs` table.
- **Optional Query Parameter:** `?run_id=<uuid>`

#### `POST /api/feedback`
Submits user ratings or comments.
- **Payload:**
  ```json
  {
    "item_type": "recommendation",
    "item_id": 1,
    "feedback_type": "like",
    "rating": 5,
    "comment": "Accurate recommendation within my budget"
  }
  ```

#### `GET /api/dashboard`
Returns aggregated data for the dashboard: user summary, top 3 predictions, top 5 recommendations, recent agent activity, and budget metrics.
